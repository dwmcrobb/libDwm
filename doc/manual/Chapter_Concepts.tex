\begin{minipage}{\textwidth}
\section{Concepts used by \texttt{Dwm::StreamIO} (C++ iostreams)}
\hypertarget{concept:HasStreamRead}{\subsection{\ttfamily HasStreamRead<T>}}
Evaluates to true if {\ttfamily T} has a member function with signature:

\conceptfsigpar{std::istream \& Read(std::istream \& is)}

\subsubsection{Required semantics}
\begin{itemize}[noitemsep,nolistsep]
  \item Must populate {\ttfamily *this} with contents read from {\ttfamily is}
  \item Must return {\ttfamily is}
\end{itemize}

\subsubsection{Other semantics}
\begin{itemize}[noitemsep,nolistsep]
  \item May set \texttt{std::ios\_base::failbit}
\end{itemize}

\hypertarget{concept:HasStreamWrite}{\subsection{\ttfamily HasStreamWrite<T>}}
Evaluates to true if {\ttfamily T} has a member function with signature:

\conceptfsigpar{std::ostream \& Write(std::ostream \& os) const}

\subsubsection{Required semantics}
\begin{itemize}[noitemsep,nolistsep]
  \item Must write the contents of {\ttfamily *this} to {\ttfamily os}
  \item Must return {\ttfamily os}
\end{itemize}

\subsubsection{Other semantics}
\begin{itemize}[noitemsep,nolistsep]
  \item May set \texttt{std::ios\_base::failbit}
\end{itemize}

\subsection{\ttfamily Dwm::IsStreamReadable<T>}
\label{concept:DwmIsStreamReadable}
Evaluates to true if \texttt{T} is a directly supported type, a type that
satisfies \hyperlink{concept:HasStreamRead}{\ttfamily HasStreamRead<T>},
an instance of a supported class template, or (if C++26 reflection is
available) is readable via reflection.

\subsection{\ttfamily Dwm::IsStreamWritable<T>}
\label{concept:DwmIsStreamWritable}
Evaluates to true if \texttt{T} is a directly supported type, a type that
satisfies \hyperlink{concept:HasStreamWrite}{\ttfamily HasStreamWrite<T>},
an instance of a supported class template, or (if C++26 reflection is
available) is writable via reflection.

\section{\ttfamily HasSkipAnnotation<std::meta::info info>}
Evaluates to true if the given reflection {\ttfamily info} has an
annotation of the form {\ttfamily [[=Dwm::skip\_io]]}

This requires C++26 reflection, specifically P2996 and P3394.

\section{Streamed length}

\subsection{Constant streamed length}
\subsection{Constant streamed length via {\ttfamily static constexpr
    uint64\_t StreamedLength()} member}
\subsection{Constant streamed length from C++26 reflection}
When using C++26 reflection for serialization and deserialization of
instances of a given type, we can determine at compile time whether
or not the streamed length of the type is constant, and hence whether
or not we can leverage {\ttfamily StreamIO} to provide
{\ttfamily DescriptorIO}, {\ttfamily FileIO}, {\ttfamily BZ2IO},
{\ttfamily GZIO} and {\ttfamily ASIO} functionality automatically
(via a pass through a {\ttfamily std::stringstream}).
